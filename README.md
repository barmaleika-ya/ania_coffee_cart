# Ania's Coffee Cart

An illustrated, interactive guide to the basic accounting conventions.
Follow Ania's coffee cart through one month and 13 transactions, and see where each one lands
on the statement of financial position, the income statement and the statement of cash flows.

- Comic strips with the journal entry, statement effects and common mistakes for each transaction
- Quiz mode: guess first, then reveal
- Statements that build step by step
- Glossary in UK/EU (IFRS), US, Polish and Russian terms
- Swipeable PDF version: [ania-coffee-cart.pdf](ania-coffee-cart.pdf)
